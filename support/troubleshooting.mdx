Argomedix VDR shows clear error messages when something goes wrong. This guide explains what each message means and the exact steps to fix it so you can keep your MedTech fundraising data room running smoothly.

## Upload and storage issues

<AccordionGroup>
  <Accordion title="Storage limit exceeded. Upgrade to Scale to upload more files.">
    This error appears when adding a file would push your workspace past its tier limit. Seed tier includes 1 GB and Scale includes 10 GB.

    **How to fix**

    1. Go to **Settings > Billing** to review your current usage.
    2. Remove unused documents or folders to free space.
    3. Upgrade to Scale if you need more room. Only the workspace owner can change tiers.

    <Note>
      The upload timer pauses during file transfers, so you will not be logged out while a large upload is in progress.
    </Note>
  </Accordion>

  <Accordion title="File size exceeds maximum limit of 2 MB.">
    Individual files uploaded to workspace settings, such as logos, must be 2 MB or smaller.

    **How to fix**

    1. Compress the image or document.
    2. Try uploading again.
  </Accordion>
</AccordionGroup>

## Share link and access code issues

<AccordionGroup>
  <Accordion title="This link is invalid or has expired.">
    The share URL you opened is no longer active. The owner or an admin may have revoked it, or it reached its expiration date.

    **How to fix**

    1. Check the link for typos.
    2. Contact the data room owner and ask for a new share link.
  </Accordion>

  <Accordion title="Invalid or inactive share link / Invalid link">
    The system could not find a matching active share link for the URL you visited.

    **How to fix**

    1. Make sure you copied the full URL, including the hash at the end.
    2. Ask the owner to confirm the link is still enabled in **Permissions > Share Links**.
  </Accordion>

  <Accordion title="Invalid invite code / This invite code has expired / This invite code is no longer active">
    The access code you entered during signup or workspace setup is invalid, expired, or was deactivated.

    **How to fix**

    1. Double-check the code for typos.
    2. If the code expired, request a new access code through the welcome flow.
    3. If you already have an account, log in instead of signing up again.
  </Accordion>

  <Accordion title="This invite code has already reached its maximum number of uses.">
    The access code you tried to use has a usage cap and that cap has been reached.

    **How to fix**

    1. Request a new invite code via the welcome flow.
    2. If you need a dedicated workspace, contact the person who shared the original code.
  </Accordion>
</AccordionGroup>

## OTP and verification issues

<AccordionGroup>
  <Accordion title="Invalid or expired verification code / Verification code has expired. Please request a new one.">
    The 6-digit OTP sent to your email is no longer valid, usually because too much time has passed.

    **How to fix**

    1. Click **Resend code** on the verification screen.
    2. Check your spam or junk folder for the new email.
    3. Enter the fresh code within a few minutes of receiving it.
  </Accordion>

  <Accordion title="Too many failed attempts. Please request a new code. / Too many attempts. Please try again in 10 minutes.">
    You entered the wrong code too many times, or you requested too many codes in a short window.

    **How to fix**

    1. Wait 10 minutes before requesting another code.
    2. Use the most recent code only. Older codes are invalidated when a new one is sent.
  </Accordion>

  <Accordion title="Incorrect verification code. X attempts remaining.">
    The code you entered does not match the one sent to your email.

    **How to fix**

    1. Check for typos, especially with similar characters like 0 and O.
    2. Make sure you are using the latest code from your most recent email.
  </Accordion>
</AccordionGroup>

## Permission and download issues

<AccordionGroup>
  <Accordion title="Access denied: You do not have permission to download this document">
    The guest account trying to download does not have download rights for that document or folder.

    **How to fix**

    1. The workspace owner or admin should open **Permissions > Groups** and confirm the group linked to the share link has **Download** access for the relevant folder or file.
    2. If the permission is set to **View** only, guests can preview but not download.
    3. If watermarking is enabled for the group, downloads may still be blocked depending on the exact permission configuration.
  </Accordion>

  <Accordion title="Only the workspace owner can manage team members / Only the workspace owner can invite team members">
    You are an admin, but the action you tried requires owner privileges.

    **How to fix**

    1. Ask the workspace owner to perform the action, such as inviting a new admin or changing the subscription tier.
    2. If ownership needs to change, the current owner can transfer ownership in **Settings > Team Members**.
  </Accordion>

  <Accordion title="Cannot invite a user as an Owner. Only one Owner is permitted per workspace.">
    You tried to invite someone with Owner rights, which is not allowed.

    **How to fix**

    1. Invite the user as an **Admin** instead.
    2. If you need to change ownership, use the **Transfer ownership** option in team settings.
  </Accordion>

  <Accordion title="Seed tier allows only 1 admin. Please upgrade to Scale. / Scale tier allows up to 10 admins. Limit reached.">
    You hit the admin seat limit for your current tier. Seed allows 1 admin and Scale allows 10.

    **How to fix**

    1. Go to **Settings > Billing** and upgrade to Scale if you are on Seed.
    2. If you are already on Scale, remove an inactive admin before inviting a new one.
  </Accordion>
</AccordionGroup>

## Session and security issues

<AccordionGroup>
  <Accordion title="For your security, you will be logged out in X:XX due to inactivity.">
    Argomedix VDR automatically logs you out after 30 minutes of inactivity. A warning appears at 25 minutes.

    **How to fix**

    1. Click **Stay Logged In** on the warning modal to reset the timer.
    2. The timer resets across all open tabs automatically when you click the button.
    3. If you are uploading files, the timer pauses so the upload is not interrupted.
  </Accordion>

  <Accordion title="User session not found. Please log in again.">
    Your session expired or was cleared, often due to inactivity or signing out in another tab.

    **How to fix**

    1. Return to the login page and sign in again.
    2. If the issue repeats, clear your browser cookies for argomedix.com and try once more.
  </Accordion>
</AccordionGroup>

## Feature request limits

<AccordionGroup>
  <Accordion title="Come back tomorrow to request more features or contact support at support@argomedix.com.">
    You reached the daily limit for submitting feature requests or upvoting ideas.

    **How to fix**

    1. Wait until the next calendar day to submit or upvote again.
    2. If you have an urgent need, email [**support@argomedix.com**](mailto:support@argomedix.com) directly.
  </Accordion>
</AccordionGroup>

## Still stuck?

If an error persists after following the steps above, email [**support@argomedix.com**](mailto:support@argomedix.com) with:

- The exact error message
- What you were trying to do
- The workspace name or share link URL (if safe to share)
