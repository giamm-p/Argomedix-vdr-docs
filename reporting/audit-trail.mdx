The Audit Log is a complete, chronological record of every significant action in your Argomedix VDR workspace. It captures activity from both team members (owner and admins) and external guests, so you always know who did what and when.

## Open the Audit Log

1. Sign in to Argomedix VDR.
2. Click **Analytics** in the top navigation bar.
3. Click **Audit Log** in the left sidebar (desktop) or the sub-tab bar (mobile).

## What Gets Logged

The system records the following action types automatically:

### Guest Actions

- **Log In**: guest login session.
- **Document Viewed**: guest opened a document (includes duration in seconds).
- **Document Downloaded**: guest downloaded a file.

### Team Actions

- **Document Uploaded**: new file added to the data room.
- **Document Replaced**: existing file overwritten with a new version.
- **Document Moved**: file moved to a different folder.
- **Document Reordered**: file position changed within a folder.
- **Document Renamed**: file name changed.
- **Document Deleted**: file removed from the data room.
- **Folder Created**: new folder added.
- **Folder Renamed**: folder name changed.
- **Folder Moved**: folder moved under a different parent.
- **Folder Reordered**: folder position changed.
- **Folder Deleted**: folder removed.
- **Group Created**: new permission group created.
- **Group Renamed**: permission group name changed.
- **Group Deleted**: permission group removed.
- **Group Permissions Updated**: folder or document permissions changed for a group.
- **Share Link Created**: new share link generated.
- **Share Link Deactivated**: share link revoked.
- **Team Member Joined**: new admin or owner added to the workspace.
- **Admin Password Changed**: admin or owner updated their password.
- **Admin Email Change Requested**: admin or owner initiated an email change.
- **OAuth Account Converted**: social login account converted to email/password.

<Tip>
  For folder and document moves, the log includes the old path and new path. For renames, it shows the previous name and the current name.
</Tip>

## Audit Log Table

The table displays the following columns for every event:

| Column | Description |
| --- | --- |
| **Timestamp** | Local date and time when the action occurred. |
| **Action Type** | Human-readable label such as "Document Viewed" or "Folder Created". |
| **User** | Name and email of the person who performed the action. |
| **Group** | Permission group the user belongs to, or "Admin" for team members. |
| **Item Type** | Category of the affected item: Document, Folder, Group, User, Permission, Share Link, Workspace, or Settings. |
| **Item** | Name of the specific document, folder, or object involved. Shows "-" when the item name is not applicable. |

## Filter the Audit Log

Use the filter bar above the table to focus on specific events. You can combine any number of filters.

### Available Filters

- **Date**: set a start date, an end date, or both to narrow the time range.
- **All Users**: select individual users, or use the bulk options **All Admins** and **All Guests**.
- **All Groups**: select one or more permission groups.
- **All Action Types**: select one or more action types such as "Document Viewed" or "Share Link Created".
- **All Item Types**: select one or more item categories.

Click the **X** inside an active filter chip to clear just that filter. Click **Reset filters** to clear every filter at once.

## Pagination

The log shows 25 entries per page. If there are more than 25 matching events, use the pagination controls at the bottom to move between pages. The footer also shows the total number of filtered activities.

## Export the Audit Log

Click **Export** in the top-right corner to download a CSV named `audit-log-report-YYYY-MM-DD.csv`. The export includes:

- The report generation date
- Any applied filters (date range, group, action type, item type)
- Every filtered entry with timestamp, action type, user name, email, role, group, item type, and item name

<Note>
  Only the currently filtered results are exported. If you want the full log, make sure all filters are cleared before exporting.
</Note>
