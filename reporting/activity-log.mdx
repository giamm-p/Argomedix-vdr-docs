The Activity Log is a real-time feed of everything happening in your data room — from document views and downloads to user invitations and permission changes. Every action taken by any participant is recorded the moment it occurs, giving you a complete, up-to-the-minute picture of data room activity without needing to ask team members for updates.

## Accessing the Activity Log

Click **Activity** in the left sidebar of any data room to open the log. By default, the log displays the most recent 500 events in reverse chronological order. Use the filter controls at the top of the page to narrow results to the specific events, users, or time periods you care about.

## What Gets Logged

ArgoMedix VDR automatically captures the following event types across all users and sessions in your data room.

| Event Type | Description |
|---|---|
| Document Viewed | User opened a document in the viewer |
| Document Downloaded | User downloaded a file |
| Document Uploaded | New file added to the room |
| Folder Created/Deleted | Structural change to folder hierarchy |
| User Invited | Invitation sent to a new user |
| User Accepted Invitation | User clicked invite link and joined the data room |
| User Access Revoked | Access removed by an admin |
| NDA Accepted | Guest accepted NDA before accessing the data room |
| Permission Changed | Folder or document permission updated |
| Settings Changed | Data room settings modified |

## Filtering the Activity Log

Use the filter panel to focus on the events most relevant to you. The following filters are available:

- **Date range** — Set a start and end date to view events within a specific window.
- **User** — Filter by a specific user's email address to see only their actions.
- **Event type** — Multi-select from the full list of event types above to display only the categories you need.
- **Document or folder** — Click any document or folder name in the log to instantly filter the view to that item's complete activity history.

All active filters are displayed as tags at the top of the log, and you can remove them individually or clear all filters at once.

## Exporting Activity Data

To export the current view of the Activity Log, click **Export** in the top right of the Activity Log panel. Choose from two formats:

- **CSV** — Exports all fields in a machine-readable spreadsheet format, suitable for further analysis or import into third-party tools.
- **PDF** — Generates a formatted report ready for sharing with stakeholders or attaching to deal documentation.

The downloaded file is automatically timestamped and includes all events matching your current filters. If no filters are applied, the export covers the full default history.

<Tip>
  Export the activity log before archiving or closing a data room to preserve a permanent record of all reviewer activity.
</Tip>
