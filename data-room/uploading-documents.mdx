Argomedix VDR lets you populate your data room by uploading files directly into folders or by replacing placeholder documents that were created during onboarding. Uploads support drag and drop, show real-time progress, and are checked against your plan's storage limit.

## Upload files to a folder

You can add documents to any folder in your data room.

<Steps>
  <Step title="Open the target folder">
    In the Data Room view, click the folder where you want to upload files.
  </Step>
  <Step title="Drag and drop files">
    Drag one or more files from your computer into the folder area and drop them. You can also click the upload zone in a folder to open the file picker and select multiple files.
  </Step>
  <Step title="Watch progress">
    A progress indicator shows the upload status while files are being sent to storage. Wait for the status to complete before navigating away.
  </Step>
  <Step title="Verify the result">
    Once finished, the new documents appear in the folder list with their file names and sizes.
  </Step>
</Steps>

## Replace a placeholder document

During onboarding, Argomedix VDR seeds a folder taxonomy with placeholder documents. You can replace any placeholder with a real file.

<Steps>
  <Step title="Locate the placeholder">
    Find the grayed-out placeholder entry in the folder. It shows the expected document name.
  </Step>
  <Step title="Drop a file onto the placeholder">
    Drag a single file directly onto the placeholder card and release it. Only one file can replace a single placeholder.
  </Step>
  <Step title="Confirm replacement">
    The placeholder status changes to uploaded, the file name updates, and the document becomes viewable.
  </Step>
</Steps>

<Warning>
  Replacing a placeholder overwrites the previous file. If a file was already uploaded, the old version is deleted from storage and cannot be recovered.
</Warning>

## Supported file types

Argomedix VDR accepts a wide range of file formats. The viewer will automatically open the correct secure viewer based on the file extension.

| Category | Supported extensions |
| --- | --- |
| Documents | PDF, DOCX, DOC |
| Spreadsheets | XLSX, XLS, XLSM |
| Presentations | PPTX |
| Images | PNG, JPG, JPEG, GIF, WEBP, SVG |
| Video | MP4, WEBM |
| Medical imaging | DCM (DICOM series) |
| 3D models | STL, OBJ |

<Note>
  STEP and IGES files are not viewable in the browser. Upload them for download-only access, or convert to STL or OBJ for in-browser 3D viewing.
</Note>

## Storage limits

Your workspace storage cap depends on your subscription tier.

| Tier | Storage limit | Admin seats |
| --- | --- | --- |
| Seed | 1 GB | 1 |
| Scale | 10 GB | 10 |

If an upload would exceed your limit, the system rejects it and shows a message asking you to upgrade. Storage usage is calculated from the total size of all uploaded documents in your workspace.

## OCR text extraction

After a PDF or image finishes uploading, Argomedix VDR runs text extraction in the background so the document becomes searchable.

- For digital PDFs, the system extracts embedded text directly.
- For scanned PDFs and images, visual OCR is performed to transcribe visible text.

You do not need to do anything to start OCR. When it completes, the document appears in search results based on its extracted content.

## Troubleshooting uploads

| Problem | Cause | Solution |
| --- | --- | --- |
| Upload fails with a storage error | File would exceed your tier limit | Remove old files or upgrade to Scale |
| Empty file error | File has 0 bytes | Check the source file and try again |
| Upload stalls | Network interruption | Refresh the page and retry the upload |
| Placeholder does not accept file | You are not an owner or admin | Only workspace owners and admins can upload or replace documents |
