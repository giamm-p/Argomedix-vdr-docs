Argomedix VDR gives you full control over how folders and documents are organized inside your data room. You can create folders, rename items, move or copy them, reorder by dragging and dropping, and clean up onboarding placeholders when you are ready.

## Folder actions

You can perform the following actions on any folder from the Data Room view. Right-click a folder or open its action menu to see the available options.

### Create a folder

1. Open the Data Room tab.
2. Click **Add New Folder** at the top of the folder list.
3. Enter a folder name and confirm.

The new folder is placed at the end of the list in the current location. If you create it inside another folder, it becomes a subfolder.

### Rename a folder

1. Open the action menu on the folder you want to rename.
2. Select **Rename**.
3. Type the new name and confirm.

The change is saved immediately and logged in the audit trail.

### Move a folder

1. Open the action menu on the folder and select **Move**.
2. Choose the destination folder, or select the workspace root to move it to the top level.

Argomedix prevents invalid moves: you cannot move a folder into itself or into one of its own descendants. When a folder is moved, its permissions are recalculated based on the destination.

### Copy a folder

1. Open the action menu on the folder and select **Copy**.
2. Choose the destination folder or the workspace root.

A new folder is created with the same name plus "(Copy)". Permissions are applied based on the destination location. If your workspace is near its storage limit, the copy may be blocked and you will see a storage limit message.

### Delete a folder

1. Open the action menu on the folder and select **Delete Folder**.
2. Confirm the deletion in the dialog.

Deleting a folder removes it and all of its contents, including subfolders and documents. This action is permanent and is recorded in the audit log.

## Document actions

Documents support the same core actions as folders, plus placeholder-specific workflows.

### Rename a document

1. Open the action menu on the document and select **Rename**.
2. Enter the new file name and confirm.

The original file name is preserved in the audit trail for reference.

### Move a document

1. Open the action menu on the document and select **Move**.
2. Choose the destination folder.

The document is reassigned to the new folder and its permissions are updated based on the destination.

### Copy a document

1. Open the action menu on the document and select **Copy**.
2. Choose the destination folder.

A duplicate document is created with "(Copy)" added to the file name. The duplicate shares the same underlying file and does not consume additional storage. If you are near your tier limit, the copy may be blocked.

### Delete a document

1. Open the action menu on the document and select **Delete Document**.
2. Confirm the deletion.

The document is removed permanently and the action is logged.

## Reorder folders and documents

Argomedix supports drag-and-drop reordering for both folders and documents.

- **Folders**: Drag a folder up or down in the folder tree to change its position. You can also drag folders between parent folders to move and reorder them at the same time.
- **Documents**: Inside any folder, drag documents to rearrange their order.

When you drop an item, Argomedix automatically updates the `index_order` values for all siblings so the sequence remains consistent. The system also detects numeric prefixes in document file names (for example, `1. Introduction`, `2. Financials`) and renumbers them automatically after reordering or when placeholders are removed.

## Placeholders

During onboarding, Argomedix seeds your data room with a folder taxonomy and placeholder documents. Placeholders are marked as **GHOST** status and serve as a checklist for the files you still need to upload.

### Replace a placeholder

1. Locate the placeholder document in the folder.
2. Drag a file from your computer and drop it directly onto the placeholder card.
3. The upload replaces the placeholder and the new file inherits the placeholder's index position.

### Remove a single placeholder

1. Open the action menu on the placeholder document.
2. Select **Remove Placeholder**.
3. Confirm the removal.

When a placeholder is removed, the remaining documents in that folder are automatically reindexed. If their file names start with a numeric prefix, the prefix is updated to match the new sequence.

### Remove all placeholders

If you want to clean up the entire data room at once, an owner can remove every placeholder and empty placeholder folder in a single action.

1. Go to **Workspace Settings**.
2. Click **Remove All Placeholders**.
3. Confirm in the dialog.

This action:

- Deletes every placeholder document (GHOST status)
- Deletes every empty folder that contains only placeholders
- Clears placeholder comments and descriptions from uploaded documents
- Reindexes all remaining folders and documents
- Updates numeric prefixes in file names to match the new order

This action is permanent and cannot be undone. It is logged in the audit trail as a workspace settings change.

## Show empty folders

By default, empty folders are hidden from guests in the data room. You can change this behavior from **Workspace Settings**.

1. Open **Workspace Settings**.
2. Find the **Show Empty Folders** option.
3. Toggle it on or off.

When enabled, guests will see folders even if they contain no documents. When disabled, empty folders are hidden from the guest view but remain visible to admins and owners for management purposes. The change is saved immediately and logged in the audit trail.

## Storage limits during copy operations

Both folder copy and document copy check your workspace storage quota. If the action would exceed your tier limit, the operation is blocked and you receive a `STORAGE_LIMIT_EXCEEDED` response. To continue, free up space or upgrade your plan. Quota notifications are sent at 80% and 90% usage.
