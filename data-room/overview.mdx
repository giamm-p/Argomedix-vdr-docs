The Data Room is the central hub of your Argomedix VDR workspace. This page explains the layout you see when you open the Data Room tab, how the folder index works, what placeholder documents are, and how the toolbar helps you upload, organize, and share content. It also covers what external guests see when they access your room.

## Data Room Tab Layout

When you open the Data Room tab, the interface is split into two main areas:

- **Left panel (desktop):** a collapsible folder tree labeled "Data Room Index" that shows every root folder and subfolder in your workspace.
- **Right panel:** the document list for whichever folder is currently selected, plus the toolbar and search bar at the top.

On mobile, the folder tree is hidden behind a button labeled **Index:** followed by the current folder name. Tapping it opens a drawer so you can navigate without losing your place.

The top navigation of the workspace contains three tabs: **Data Room**, **Permissions**, and **Analytics**. The Data Room tab is where all document management happens. The Permissions tab is where you create groups, set per-folder access levels, and manage share links. The Analytics tab shows activity, guest lists, active links, and the audit log.

## Folder Tree and Index Numbering

Argomedix automatically numbers every folder and document so your data room stays organized without manual ordering. The system uses a dotted index format such as `1.`, `1.1`, `1.2.3`.

The numbering rules are:

- Root folders get single numbers: `1. Executive Summary`, `2. Corporate & Legal`, `3. Financials`.
- Subfolders append a second level: `2.1 Incorporation & Governance`, `2.2 Material Contracts`.
- Documents inside a folder continue the sequence: `2.1.1 Certificate_of_Incorporation.pdf`, `2.1.2 Corporate_Bylaws.pdf`.

If you rename a file to include its own structural prefix (for example, `1.1 Pitch_Deck.pdf`), the system detects the prefix and preserves it instead of generating a new one. This lets you align the index with your own numbering scheme when needed.

You can drag folders and documents to reorder them. The index recalculates automatically after each move.

## Placeholder Documents from Onboarding

During onboarding, Argomedix seeds your workspace with a MedTech fundraising folder taxonomy based on your startup stage, product type, and clinical risk level. The taxonomy includes folders such as:

- Executive Summary
- Corporate & Legal
- Financials
- Regulatory & Quality
- Clinical & Product Development
- Intellectual Property
- Operations & IT

Each folder contains placeholder documents with suggested filenames. Placeholders appear as dashed-border cards labeled **Placeholder** and can be replaced in two ways:

1. Click the **Upload Document** button on the placeholder card.
2. Drag and drop a file directly onto the placeholder card. The card highlights in blue when a file is dragged over it.

You can also remove a placeholder entirely by clicking the **X** icon that appears on hover.

## Toolbar Actions

The toolbar sits above the document list and provides the main actions you need to manage content.

### Search

A persistent search bar labeled **Search in Data Room...** sits at the top center of the page. It supports full-text search across document names and OCR-extracted text. Results appear in a dropdown as you type. Press Enter to open the full search results page.

### Upload and Create Folder

- **Upload documents:** click the plus icon in the toolbar, or drag files onto the dashed dropzone at the bottom of any folder. You can also click **Upload document** on any placeholder card.
- **Create folder:** use the three-dot menu next to the folder title to add a sibling folder, add a subfolder, rename, move, or delete the current folder.

### Share Data Room

The **Share Data Room** button in the top-right opens a modal where you can generate a share link tied to a permission group. You can optionally set an expiration date and time for the link. Once generated, the link is copied to the clipboard and can be revoked later from the Permissions tab.

## What Guests See

When an external investor (guest) opens a share link, they see a simplified version of the Data Room:

- The same folder tree and index numbering, but only folders and documents their group has permission to view.
- Hidden folders are completely omitted. Empty folders are also hidden unless your workspace settings explicitly show them.
- Guests can click any document they have access to and open it in the secure viewer. Supported formats include PDF, DOCX, PPTX, XLSX, images, video, DICOM, and CAD files (STL and OBJ).
- If their group permission is **download** and watermarking is not enabled for the link, they can download the original file. If the link has watermarking turned on, downloads are disabled and the document is view-only.
- Guests register with name and email, then verify access via an email OTP before they can see any content.

Guests do not see upload buttons, folder creation menus, or the Share Data Room control. Their experience is strictly view and download based on the permissions you set in the Permissions tab.

## Key Concepts

<CardGroup cols={2}>
  <Card title="One workspace = one data room" icon="box">
    Your Argomedix account is tied to a single workspace. There is no concept of multiple data rooms or archived rooms. All documents live in the same indexed folder tree.
  </Card>
  <Card title="Owner and admin roles" icon="users">
    Only the workspace owner and admins can upload, create folders, rename, move, delete, and share.
  </Card>
  <Card title="Per-group permissions" icon="shield">
    Access is controlled by Groups. Each group can be set to hidden, view, or download on any folder or document. Watermarking can be toggled per share link, not per user.
  </Card>
  <Card title="Secure viewers" icon="eye">
    Documents open in browser-based secure viewers. PDF, Office, images, video, DICOM, and CAD files are supported. No external software is required for guests.
  </Card>
</CardGroup>
