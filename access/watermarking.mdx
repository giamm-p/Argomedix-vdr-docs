Argomedix VDR applies dynamic watermarks to documents so that every view and every download can be traced back to the individual guest. The watermark is rendered in real time and includes the guest's identity, session timestamp, and network address.

## What the watermark contains

Every watermark displays three lines of information:

1. **User email** (the guest's registered email address)
2. **Timestamp with UTC offset** (the local time when the session started)
3. **Client IP address** (resolved from the request headers, or `127.0.0.1` in local development)

In the viewer, these three lines are shown as a single line with bullet separators when a compact representation is needed. In the overlay grid, they appear as three stacked lines repeated across the page at a -45 degree angle.

## Where watermarks appear

Watermarks are applied in the secure viewer for every supported document type:

- **PDF** (Canvas-rendered grid overlay)
- **Images** (PNG, JPG, GIF, WEBP, SVG) (drawn directly onto the Canvas)
- **DOCX, PPTX, XLSX** (SVG pattern tile overlay)
- **Video** (MP4, WEBM) (SVG overlay on the video element)
- **DICOM** (`.dcm`) (viewer-level overlay)
- **CAD** (`.stl`, `.obj`) (viewer-level overlay)

When watermarks are enabled, the watermark also gets embedded permanently into downloaded PDF files. For images, the watermark is drawn onto the canvas before the download is generated.

## Default watermark setting

The workspace owner controls the default behavior from **Workspace Settings** under the **Customization** section. The setting is labeled **Watermark on Files** and has two options:

- **Original files (No Watermark - Default):** Watermarks are disabled. Guests see and download the original file without any overlay.
- **Watermarked Files:** Watermarks are enabled for all viewers and downloads.

The default for new workspaces is **Original files (No Watermark)**. Changing this setting updates the Permissions page in real time and triggers an audit log entry.

<Note>
  Only the workspace owner can change the default watermark setting. Admins can still toggle watermarks on individual items.
</Note>

## Per-item watermark toggle

Inside the **Permissions** page, when you select a group and open the **Data Room Permissions** tab, each folder and document row has a **Watermark** checkbox column. You can toggle watermarking independently for every item:

- Checked: the item is watermarked for guests in that group.
- Unchecked: the item is shown without a watermark for guests in that group.

If the workspace default is set to **Original files (No Watermark)**, the Watermark column is disabled and shows a tooltip: **Watermarked files are not enabled.** A **Change Settings** link inside the tooltip opens the workspace settings modal so the owner can enable watermarking globally.

## How permissions interact with watermarking

Watermarking is only relevant when the permission level is **View** or **Download**. If an item is set to **Hidden**, the watermark toggle is inactive because the guest cannot see the item at all.

When a guest opens a document, the viewer checks the resolved permission for that document. If the document inherits its permission from a parent folder, the watermark setting is inherited as well. If the document has an explicit permission override, its own watermark flag is used.

## Downloads and watermarks

When the workspace default is **Watermarked Files**, downloads are disabled entirely for guests. The guest sees a message that downloads are disabled for this file. This applies across all document types.

When the workspace default is **Original files (No Watermark)** and a specific item has its watermark toggle turned on, the behavior depends on the viewer:

- In the **PDF viewer**, the download button is still available if the permission is **Download**, but the downloaded file is permanently watermarked with the guest's identity.
- In the **image viewer**, the watermark is drawn onto the canvas before the download starts.
- For **DOCX, PPTX, XLSX, and video**, the download is blocked if watermarking is enabled for that item.
